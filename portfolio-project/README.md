# GCP Kubernetes Operations Portfolio

This folder links to a separate personal lab project prepared to demonstrate Cloud Operations fundamentals. It is intentionally kept separate from TechQuest, the Professional Cloud Developer exam-practice PWA.

Download the standalone project ZIP from the related ChatGPT conversation and publish it in a new repository named `gcp-kubernetes-operations-portfolio`.

## Project scope
- Python script for offline reporting from synthetic metrics and sample security findings.
- Example Kubernetes YAML: Deployment, Service, HPA and ResourceQuota.
- IAM/findings review checklist, GKE runbook and cost-analysis framework.
- Unit tests and instructions to run locally.

All included sample data is fictional. The project does not connect to GCP and contains no employer/client data or credentials.
